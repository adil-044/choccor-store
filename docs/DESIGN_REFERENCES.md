# Design References — Choccor Homepage

## Primary direction (Nov 2026) — Amboras editorial commerce

Adil’s reference set (attached cards): **L’Duchen Maison**, **Grain & Glass**, **Grove & Glass**, **Harvest & Root**, **Northline**, **Lumene & Co.**

Patterns applied:

- Light cream/linen paper ground, one deep accent (cocoa) on ticker + CTAs, gold secondary
- High-contrast serif wordmark/headings, wide-tracked caps labels, italic subheads, mono spec lines
- Hairline rules, rounded option cards, sparse flourishes
- Featured-product split (large photo + thumbnails + buy panel)
- Photography-led merchandising; subtle motion only

Earlier Awwwards/ThemeForest notes below informed an earlier dark/3D direction that was rejected and archived (`archive/3d-showcase`).

## Patterns applied on Choccor

1. **Bold editorial typography** — oversized serif display with split-word/line reveals  
2. **Oversized real product imagery** — Courtney’s cream-studio mockups only  
3. **Scroll-pinned storytelling** — Build-a-box and tray chapters pin while copy progresses  
4. **Horizontal product rail** — featured chocolates as a scrubbed/scrollable runway  
5. **Magnetic CTAs** — Shop / Build a Box buttons with subtle cursor magnetism  
6. **Soft cursor glow** — cream/cocoa ambient follow (disabled under reduced motion)  
7. **Lenis smooth scrolling** — paired with GSAP ScrollTrigger  
8. **Cream ↔ dark chocolate contrast** — light merchandising vs rich cocoa chapters  
9. **Conversion clarity** — persistent Shop + Build a Box paths; Price TBC placeholders only  

## Hard constraints (unchanged)

- Real product images only  
- Placeholder prices (`Price TBC`)  
- No phone numbers  
- No invented reviews, ingredients, or product names for unnamed BYOB bars
